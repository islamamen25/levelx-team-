**معيار القبول:** `grep -rn "£" app components messages` = صفر نتائج.

### 2. نظام الأرقام في الأسعار 🟠

`components/plp/product-card.tsx:12` يستخدم `Intl.NumberFormat("ar-EG", …)` فيُخرج أرقاماً هندية `١٬٣٠٠`، بينما أسماء المنتجات بأرقام غربية → تضارب داخل البطاقة الواحدة. مصر تجارياً تستخدم الأرقام الغربية.

```ts
// قبل
new Intl.NumberFormat(locale === "ar" ? "ar-EG" : "en-EG", { … })
// بعد — نفس اللغة، أرقام لاتينية
new Intl.NumberFormat(locale === "ar" ? "ar-EG-u-nu-latn" : "en-EG", { … })
```
طبّق نفس التعديل في أي ملف آخر يستدعي `Intl.NumberFormat` بـ `ar-EG` (ابحث عنها).

### 3. ترجمة شرائح الهيرو إلى العربية 🔴

### 5. استبدل الإيموجي بصور منتجات حقيقية 🔴

`hero-slider.tsx` — الحقل `emoji` يُرسم بـ `fontSize: clamp(5rem, 12vw, 11rem)` (سطر ~159). إيموجي كصورة منتج = أوضح علامة على موقع غير مكتمل، ويُرسم مختلفاً على كل نظام تشغيل.

استبدله بحقل `image` و `next/image` **مع `width`/`height` صريحين** (3 صور حالياً بلا أبعاد = مخاطر CLS):
